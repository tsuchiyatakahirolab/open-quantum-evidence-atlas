# Changelog

## 1.0.0 — 2026-08-13

First stable public release for the OpenAIRE AI Hackathon, archived as [DOI 10.5281/zenodo.21913414](https://doi.org/10.5281/zenodo.21913414).

- Publishes the 29 July 2026 OpenAIRE snapshot and complete 645-record audit.
- Provides a no-login Atlas, reusable Evidence Chain Auditor and 119-second walkthrough.
- Uses Alien/OpenAIRE MCP for interactive verification and the direct Graph API for deterministic census counts.
- Includes reproducible code, notebook, data, machine-readable manifests and responsible-use boundaries.
- Requires authenticated OpenAIRE access only for an uncached full-census rerun; snapshot review and the bounded 22-request check remain credential-free.
- Separates the verified 29 July full census from the 8 August bounded drift observation, including Q‑NEKO's first detected project record.
